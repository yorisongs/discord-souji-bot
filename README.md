# 掃除Bot

Discordのチャンネルのメッセージをまとめて削除するBotです。

## コマンド

### `/purge count:<件数> [user:<ユーザー>]`
直近のメッセージを、指定した件数だけ削除します。

| 項目 | 必須 | 説明 |
|---|---|---|
| `count` | ○ | 削除する件数（1〜1000） |
| `user` | – | 指定すると、そのユーザーのメッセージだけを削除します |

例：
- `/purge count:50`：直近50件を削除
- `/purge count:100 user:@太郎`：直近100件のうち、太郎さんのメッセージだけを削除

### `/purge_all`
チャンネル内の、直近14日以内のメッセージをすべて削除します。

## 誰が使えるか
- 「メッセージの管理」権限を持つ人だけが使えます。
- 権限のない人には、コマンドの候補自体が表示されません。

## 処理の流れ
1. コマンドを受け取ると、Botが「考え中…」の状態になります（削除に時間がかかるため）。
2. チャンネルのメッセージを新しい順に調べ、条件に合うものを削除します。
3. 終わると「〇件削除しました。」と表示します。この結果は実行した本人にしか見えません。

## 制限・注意
- **14日より古いメッセージ**：Discordの仕様でまとめて削除できません。`/purge` では1件ずつ削除するので時間がかかり、`/purge_all` では削除されません。
- **削除したメッセージは元に戻せません。**
- `user` を指定した場合、`count` は「調べる件数」の意味になります。たとえば `count:100` なら直近100件を調べ、その中の該当者のメッセージだけを削除します。
- Botを起動している間だけ使えます。

## 起動方法
1. フォルダ内の `start.bat` をダブルクリックします。
2. 黒い画面に `connected to Gateway` と出たら起動完了です。
3. 黒い画面を閉じるとBotは止まります。

※ 二重起動はできません。同じPCで既に起動中の場合は「Botは既に起動しています。終了します。」と表示されて終了します（別のPCで同時に起動した場合は防げません）。

## 初回の準備（導入する人向け）
- PCにPythonをインストールしておきます。
- `.env` に `DISCORD_TOKEN=Botトークン` と書きます（`.env.example` をコピーして使えます）。
- 招待URLでBotをサーバーに招待します。必要な権限は「チャンネルを見る」「メッセージの管理」「メッセージ履歴を読む」です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `bot.py` | Bot本体 |
| `start.bat` | 起動用（ダブルクリック） |
| `.env` | トークン（**他人に共有しないこと**） |
| `.env.example` | `.env` のひな形 |
| `requirements.txt` | 必要なライブラリの一覧 |
| `README.md` | この説明書 |

フォルダごと移動しても、そのまま動きます。
